# РЕФЕРЕНС — иконка плеера, знак «волна»

> Решение владельца, 2026-10-16: *«мне нравится чистота, минимализм, единая
> концепция; я очень впечатлён концепцией иконки плеера — волна, цвет фона и
> волны в принципе устраивают; надо это в референсы добавить обязательно»*.
> Статус: **обязательный референс и основа единой айдентики зоопарка.**

Источник — `dajet-player`, PR #11, ветка `arena/9e9c91a8`. Файлы-источники скопированы
сюда, чтобы референс не зависел от судьбы PR.

## Что берём

| Что | Значение |
| --- | --- |
| Плита | `#15181C` |
| Знак | `#E8AE8C`, терракота — единый акцент серии |
| Форма знака | волна (синус), штрих **74** при канве 1024 |
| Концы штриха | скруглённые (`stroke-linecap: round`) |
| Канва | 1024 × 1024, тело знака **824** |
| Угол плиты | непрерывный, суперэллипс n = 5, `0.2253 × 824` |
| Цветов в иконке | **ровно два** (плита и знак) |
| Плоскость | без градиентов, теней, обводок и полупрозрачностей |
| Масштаб | знак обязан читаться в 16 × 16 |

## Чего не берём

* **`.icns` из PR #11 целиком.** Там записи 16 и 32 нарисованы с подменённым
  штрихом (96 вместо 74) — это и есть дефект F-1. `.icns` пересобран из вектора
  инструментами из [`../tools/`](../tools/); исходная сборка сохранена рядом как
  `legacy-broken.icns` — чтобы дефект был виден, а не только описан.
* **Правило «штрих 96 на 16 и 32 px».** Именно оно породило брак: две записи,
  нарисованные «иначе», вышли пустыми и мутными. В концепции штрих один — 74,
  а тонкость на малых размерах решает рендерер, а не ручная подмена.
* **Заготовку с наушниками** из `apps/brand/icons/dajet-player.icns`: это временный знак
  координатора, нарисованный до появления настоящей иконки. Теперь он устарел и
  подлежит замене на волну.

Все десять записей: и плита, и знак, ни одной пустой, ни одного чужого цвета.
«Сверка с вектором» — ноль: запись побайтово совпадает с рендером того же
вектора на ту же сторону.

Для сравнения — та же проверка на `legacy-broken.icns` (`node tools/check-icons.mjs
signs/dajet-player/legacy-broken.icns`) даёт **ненулевой код выхода** и три
замечания: записи `16×16`, `16×16@2x` и `32×32` расходятся с вектором
(0.036 / 0.040 / 0.040) — это те три записи, которые PR #11 рисовал с подменённым
штрихом. Остальные семь сходятся.

## Как применяется

Референс задаёт **инвариант серии**: плита, акцент, количество цветов, сетка, штрих,
правило проверки в 16 px. Всё, что этому не противоречит, — свободно (знак конкретного
приложения, композиция внутри плиты). Всё, что противоречит, — либо меняется, либо
объявляется осознанным исключением с записанным правилом.
