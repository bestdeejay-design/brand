# brand — единая айдентика зоопарка

> Канон **v1.0.0**, 2026-10-16. Решение владельца: чистота, минимализм, единая
> концепция. Основа — иконка плеера, знак «волна» на тёмной плите.

Зоопарк: Dajet Player, Dajet Editor, Dajet Browser, JOER Radio и коты-питомцы
(Sweet No Sleep). У каждого — свой знак; язык у всех один.

## Что в репозитории

| Файл | Что это |
| --- | --- |
| [`CONCEPT.md`](CONCEPT.md) | Канон: инвариант, знаки, исключение для персонажей, чек-лист сдачи |
| [`palette.json`](palette.json) | То же машинночитаемо: цвета, геометрия, правила `.icns`, состояние знаков |
| [`reference/player-icon-wave/`](reference/player-icon-wave/) | **Обязательный референс** — эталон серии: вектор, рендер 1024, запись 32 px |
| [`reference/browser-icon-d/`](reference/browser-icon-d/) | Знак браузера: иконка, `.icns`, мок на тёмной плите, лист сравнения |

## Инвариант в одну строку

Плита `#15181C`, акцент `#E8AE8C`, ровно два цвета, плоско (без градиентов, теней и
свечений), канва 1024 с телом 824, суперэллипс `n = 5`, штрих 74, обязательная
проверка чтения в 16 px, `.icns` собирается только из вектора.

## Знаки

| Кто | Знак | Состояние |
| --- | --- | --- |
| Dajet Player | волна | есть — эталон серии |
| Dajet Editor | наушники (вторая половина пары «волна / наушники») | сделать |
| Dajet Browser | D-апертура | есть; плита белая → тёмная |
| Kiwi Cat, Watermelon Cat | кот-персонаж | есть; плита светлая → тёмная; исключение из правила двух цветов — записано |
| JOER Radio | эквалайзер | есть; убрать градиент и гало, плита и акцент общие |

## Чего в репозитории нет

Рабочих материалов разбора: распакованных записей иконок, увеличенных кадров
читаемости, замеров и журнала находок. Они живут локально у координатора
(`apps/brand/`, индекс — `SURVEY.md`) и намеренно не выкладываются: это рабочий
стол, а не канон.
